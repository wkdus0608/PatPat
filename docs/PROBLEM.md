문제 정의서 (PROBLEM)

1. **한 문장 문제**
여러 아동의 알림장·관찰일지를 쓰는 어린이집 담임 교사가, 당일 또는 작성 대상 기간의 관찰을 되찾아 아동별로 정리하는 일을 보육 시간 안에 끝내지 못해 기록을 미루거나 아이별 사실을 생략하게 된다. 관찰일지는 기록 간격이 길어 그간의 일을 되찾는 부담이 특히 크다.

2. **대상과 비대상**
- 1차 사용자: 4명 이상 아동을 담당하며 알림장 또는 관찰일지를 직접 작성하는 어린이집 담임 보육교사. 알림장 미작성 기관도 포함한다. (기존 조사: 로그 1, 2, 4~10 / 지원 범위: 팀 정의)
- 비대상(현재): 원장·행정 담당자, 보호자

알림장은 사용하는 기관에서 매일 보호자와 그날의 일상·특이사항·안부를 공유하는 기록이다. 관찰일지는 월 1~2회 이상, 대상 기간에 확인한 아동의 관찰을 모아 작성하는 기록이다. 주기와 두 기록 지원은 팀의 제품 정의이며, 기존 조사에서 말한 기관별 ‘일지’ 서식을 모두 관찰일지로 해석하지 않는다.

3. **증거**
- 기록이 보육 시간 밖으로 밀림 → 휴게시간·퇴근 후 작성("일과중에는 작성할 수 없어서" — 로그 1, 2, 4, 5, 6, 7, 8, 9, 10)
- 아이별 행동을 되찾으려 여러 증거원을 오감(사진, 동료, 아동, 교구로 확인 — 로그 1, 2, 4, 5, 7, 8, 9)
- 시간이 부족하면 아이별 기록이 공통문으로 대체("바쁘면 똑같이 씀" — 로그 4, 5, 6)
- 범위 밖 부수 업무: 사진 선택·정리에도 약 30분이 걸린 사례가 있으나, 현재 제품은 사진 정리·분류를 지원하지 않음. (로그 7, 9)
- 부상·민감 사항은 부모 오해를 막는 문장 검토가 필요함(로그 2, 3, 5)

4. **반증 조건**
4-1. **문제의 실재** (인터뷰 증거로 지금 판정)
  - 주장: 4명 이상 아동을 담당하는 어린이집 담임 교사는 흩어진 근거에서 아이별 행동을 되찾아 구분해 쓰는 일을 보육 시간 안에 끝내지 못해, 기록을 미루거나 아이별 내용을 공통문으로 대신한다.
  - 반증 조건: 대상 교사 9명(로그 3 제외) 중 최근 작성에서 ① 아이별 행동을 되찾느라 기억 외 근거를 찾았거나 회상이 가장 오래 걸렸고, ② 기록을 미루거나 공통문으로 대신한 사례가 5명 미만이면 문제 정의 기각 — 대상 또는 문제를 다시 쓴다. (현재 7명: 로그 1, 2, 4, 5, 6, 7, 8 → 유지)

4-2. **해결 가설** (제품 사용 관찰로 이후 판정)
  - 가설: "음성·텍스트로 입력한 관찰을 공통 활동과 아이별 사실로 분리한 초안"이 기록을 나눠 쓰는 노동을 줄인다.
  - 반증 조건: 관찰이 정확히 반영된 초안을 받고도 교사가 아이별 내용을 다시 나누어 작성해야 하거나, 아이별 문장을 공통문으로 덮어쓰거나, 퇴근 후로 미루면 가설 기각. 초안에 관찰이 빠지거나 없는 사실이 들어가 고친 사례는 가설이 아니라 생성 품질(AC1)의 문제로 따로 센다.

5. **성공의 정의** (행동 지표)
- 교사가 아이별 초안을 검토해 확정(저장·복사)까지 가는 비율(활성화)
- 알림장은 다음 작성일, 관찰일지는 다음 작성 주기에 다시 사용(기록 유형별 리텐션)
- 록을 휴게시간·퇴근 후가 아닌 업무시간 안에 끝낸 비율(업무시간 내 완료)

6. **해결 방식의 제약** (팀 회의 결정, 인터뷰 증거와 구분)
- 개인정보 문제로 음성 전사·이름 가명 처리는 로컬 AI로 수행한다. 외부 AI API는 가명 텍스트의 아동별 분류·기록 생성만 맡고, 실명 매핑 보관과 복원은 로컬에서 한다. 상세 계약은 SPEC 4절·AC10을 따른다.
