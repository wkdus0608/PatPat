# 문제 정의서 (PROBLEM)

## 1. 한 문장 문제
어린이집 담임 교사는 여러 아동의 관찰을 아동별로 되찾아 정리할 시간이 없어, 기록을 퇴근 후로 미루거나 아이별 내용을 공통문으로 대신한다.

## 2. 대상
- **사용자**: 4명 이상 아동을 맡아 알림장 또는 관찰일지를 직접 쓰는 어린이집 담임 교사 (로그 1, 2, 4~10)
- **비대상**: 원장·행정 담당자, 보호자

## 3. 증거
- 기록이 업무시간 밖으로 밀린다. "일과중에는 작성할 수 없어서" (로그 1, 2, 4~10)
- 아이별 행동을 되찾으려 사진·동료·아동·교구를 다시 확인한다. (로그 1, 2, 4, 5, 7, 8, 9)
- 바쁘면 아이별 기록을 공통문으로 대신한다. "바쁘면 똑같이 씀" (로그 4, 5, 6)
- 부상·다툼은 보호자 오해를 막는 문장 검토가 필요하다. (로그 2, 3, 5)

## 4. 반증 조건
- **문제**: 대상 교사 9명(로그 3 제외) 중 ① 기억 밖 근거를 찾았거나 회상에 가장 오래 걸렸고 ② 기록을 미루거나 공통문으로 대신한 교사가 5명 미만이면 문제를 다시 쓴다. 현재 7명(로그 1, 2, 4~8)이라 유지한다.
- **해결 가설** ("관찰을 공통 활동과 아이별 사실로 나눈 초안이 기록 노동을 줄인다"): 정확한 초안을 받고도 교사가 아이별 내용을 다시 나눠 쓰거나, 공통문으로 덮어쓰거나, 퇴근 후로 미루면 기각한다. 초안의 누락·지어낸 사실은 생성 품질 문제로 따로 센다.

## 5. 성공 지표
- 초안을 확정(저장·복사)까지 가져가는 비율
- 다음 작성일(알림장)·다음 작성 주기(관찰일지)에 다시 쓰는 비율
- 기록을 업무시간 안에 끝낸 비율

## 6. 제약 (팀 결정)
개인정보 보호를 위해 음성 전사·이름 가명 처리는 로컬 AI가 하고, 외부 AI는 가명 텍스트로 분류·초안 생성만 한다. (SPEC 4절)
