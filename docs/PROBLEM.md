문제 정의서 (PROBLEM)

1. **한 문장 문제**
여러 아동의 기록을 쓰는 어린이집 담임 교사 일부는 아이별 놀이·행동·반응을 떠올리거나 글로 옮기는 데 부담을 겪고, 개별 내용을 공통문으로 대신하거나 기록을 퇴근 후에 작성한다(로그 4, 6, 9).

2. **대상과 비대상**
- 1차 사용자: 여러 아동을 담당하며 알림장 또는 관찰일지를 직접 작성하는 어린이집 담임 보육교사. 알림장을 매일 쓰지 않는 기관도 포함한다. (기존 조사: 로그 1~10 / 지원 범위: 팀 정의)
- 비대상(현재): 원장·행정 담당자, 보호자

알림장은 사용하는 기관에서 매일 보호자와 그날의 일상·특이사항·안부를 공유하는 기록이다. 관찰일지는 월 1~2회 이상, 대상 기간에 확인한 아동의 관찰을 모아 작성하는 기록이다. 

3. **증거**
- 실제 작성 지연은 로그 1, 4, 5, 6, 7, 8, 9에서 확인된다. 로그 2와 10은 일과 중 작성 시간 부족을 말한다.
- 아이별 반응을 다르게 적는 부담(로그 4), 그날의 놀이·행동을 떠올리는 부담(로그 6), 아이별 행동을 짧게 적는 부담(로그 9), 관찰한 일을 글로 옮기는 부담(로그 10)이 확인된다. 교사는 메모를 활용하거나 아동에게 다시 확인하기도 한다(로그 7, 관찰 3).
- 시간 부족으로 개별 기록을 공통문으로 대신한 사례는 로그 4의 “그래서 바쁘면 그냥 다 똑같이 작성해요.”다. 로그 6은 회상 부담에 따른 일괄 작성을, 로그 5·8·9는 공통 내용에 특이사항이나 개별 반응을 덧붙이는 방식을 보여준다.
- 관찰일지를 미루거나 퇴근 후 작성한 사례는 로그 4·6·7에 있다. 로그 8은 한 주의 일과를 제한된 분량에 압축하는 부담을 보여준다.
- 부상·민감 사항은 부모 오해를 막는 문장 검토가 필요함(로그 2, 3, 5)

4. **반증 조건**
4-1. **문제의 실재** (인터뷰 증거로 지금 판정)
  - 주장: 여러 아동을 담당하는 어린이집 담임 교사는 같은 활동도 아이별로 떠올려 다르게 쓰는 일을 보육 시간 안에 끝내지 못해, 기록을 미루거나 아이별 내용을 공통문으로 대신한다.
  - 반증 조건은 대상 교사 10명 중 최근 작성에서 ① 아이별 문장 작성이나 행동 회상이 부담이었고 ② 기록을 미루거나 개별 내용을 공통문으로 대신한 교사가 5명 미만이면 기존 문제 정의를 기각하고 대상 또는 문제를 다시 쓰는 것이다.
  - 아래 재집계는 공개된 [인터뷰 로그](research/interviews.md)의 직접 진술을 기준으로 한다. 진술에서 확인하기 어려운 항목은 미확인으로 표시했다. 로그 대부분은 특정 작성일을 제시하지 않아 최근 작성 사건 여부는 별도 확인이 필요하다.

| 로그 | ① 개별 작성·회상 부담 | ② 지연·공통문 대체 |
| --- | --- | --- |
| 1 | 미확인. 개별 작성은 관행으로 설명 | 퇴근 후 작성 경험 |
| 2 | 미확인. 부상 경위 설명이 가장 오래 걸림 | 미확인. 업무시간 부족만 진술 |
| 3 | 미확인. 오해를 막는 부상 설명이 부담 | 미확인 |
| 4 | 아이별 반응을 다르게 쓰는 데 시간이 걸림 | 바쁠 때 공통문으로 대체하고 일지를 미룸 |
| 5 | 미확인. 민감한 문장 수정이 부담 | 퇴근 후 작성 경험 |
| 6 | 아이별 놀이·행동 회상이 가장 오래 걸림 | 같은 활동은 일괄 작성하고 일지를 퇴근 후에 쓴 경험이 있음 |
| 7 | 미확인. 기억·메모 활용은 관행으로 설명 | 일지를 퇴근 후에 작성 |
| 8 | 미확인. 지도 방향 설명과 일지 압축이 부담 | 기록을 미룬 경험 |
| 9 | 아이별 행동을 짧게 쓰는 데 시간이 걸림 | 공통문을 복사하고 시간이 부족하면 퇴근 후 작성 |
| 10 | 관찰한 일을 글로 옮기는 데 시간이 걸림 | 미확인. 일과 중 작성이 어렵지만 실제 작성 시점은 제시하지 않음 |

두 조건이 직접 확인된 사례는 **3명(로그 4·6·9)**이다. 로그 10의 업무시간 부족을 실제 작성 지연으로 해석하면 4명으로, 중간평가의 집계와 같고 5명 기준에 미달한다. 기존 ‘7명 충족’ 판정은 철회하고 1절의 문제 문장을 로그에서 확인한 일부 교사의 경험으로 좁혔다.

4-2. **해결 가설** (제품 사용 관찰로 이후 판정)
  - 가설: "음성·텍스트로 입력한 관찰을 공통 활동과 아이별 사실로 분리한 초안"이 기록을 나눠 쓰는 노동을 줄인다.
  - 반증 조건: 관찰이 정확히 반영된 초안을 받고도 교사가 아이별 내용을 다시 나누어 작성해야 하거나, 아이별 문장을 공통문으로 덮어쓰거나, 퇴근 후로 미루면 가설 기각. 초안에 관찰이 빠지거나 없는 사실이 들어가 고친 사례는 가설이 아니라 생성 품질(AC1)의 문제로 따로 센다.

5. **성공의 정의** (행동 지표)
- 교사가 아이별 초안을 검토해 확정(저장·복사)까지 가는 비율(활성화)
- 알림장은 다음 작성일, 관찰일지는 다음 작성 주기에 다시 사용(기록 유형별 리텐션)
- 기록을 휴게시간·퇴근 후가 아닌 업무시간 안에 끝낸 비율(업무시간 내 완료)

6. **해결 방식의 제약** (팀 회의 결정, 인터뷰 증거와 구분)
- 초기 장기 설계: 개인정보 문제로 음성 전사·이름 가명 처리는 로컬 AI로 수행한다. 외부 AI API는 가명 텍스트의 아동별 분류·기록 생성만 맡고, 실명 매핑 보관과 복원은 로컬에서 한다. 상세 계약은 SPEC 4절·AC6을 따른다.

- 현재 MVP에서 교사는 텍스트나 선택 녹음으로 알림장 초안을 작성하고 검토·수정·확정한다. 연결된 관찰일지 초안을 함께 준비할 수 있으며, 확정된 기록은 아동·관찰일별로 조회·편집한다. 알림장 없이 관찰일지를 새로 작성하는 흐름은 기존 지원 요구와 현재 구현 사이에 남아 있다.
- 원음은 서버의 비공개 영역에 보관하고 선택 녹음만 전사한다. 전사 요청과 결과 재사용 경로가 구현돼 있으며 실제 외부 STT 공급자는 별도로 연결해야 한다. 텍스트 AI에는 작업에 따라 선택 전사문·교사 입력·아동 정보가 전달될 수 있다. 현재 범위와 인터페이스는 [SPEC](SPEC.md) 4절과 5-1~5-2절을 따른다.
