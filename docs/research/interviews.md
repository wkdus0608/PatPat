# 인터뷰 프로토콜과 착수 기록

교사 표기는 설문 제출 순서대로 보육교사 A~J를 사용한다. 이름, 연령, 경력, 기관명은 기록하지 않는다. 문서의 기록 일시는 CSV 타임스탬프(GMT+9)를 사용한다. 로그 번호 1~10은 제출 순서와 같으며 이후 관찰 기록과 온톨로지의 `evidence`가 이 번호를 참조한다.

## 1. 인터뷰 프로토콜 v1

- **대상(행동 조건)**: 최근 알림장 또는 일지를 직접 작성했고, 작성 시작부터 검토·마무리까지 자신의 행동을 설명할 수 있는 보육교사.
- **알아내려는 것(반증 가능한 가설)**: 여러 아동의 기록 작성 비용은 문장 입력 자체보다 관찰 근거를 다시 찾고, 공통 활동을 아동별 행동으로 구분하고, 민감한 표현과 기록 기준을 검토하는 과정에서 커진다.
- **사건 범위**: 한 번의 최근 작성 경험을 시작 시점부터 최종 저장·전달까지 따라간다. 알림장과 일지를 함께 말할 때는 각각의 시간과 단계를 분리한다.
- **운영 원칙**: 제품이나 해결책을 설명하지 않는다. 미래 의향, 가정 상황, 일반적인 의견을 묻지 않는다. “보통은”이라는 답이 나오면 가장 최근의 한 번으로 돌아간다. 칭찬이나 기능 요청이 나오면 그 말을 평가하지 않고, 그 전에 실제로 쓴 우회로와 발생한 비용을 묻는다.

### 핵심 질문 5개

| # | 질문 | 질문 의도 |
|---|---|---|
| Q1 | 가장 최근 알림장이나 일지를 작성한 날을 떠올려 주세요. 언제 시작했고, 몇 명분을 썼으며, 끝날 때까지 얼마나 걸렸나요? | 최근의 구체적 사건을 고정하고 작업량과 실제 시간 비용을 확보한다. |
| Q2 | 작성하기 직전부터 끝낼 때까지 실제로 한 일을 순서대로 말씀해 주세요. 각 단계에서 무엇을 보거나 누구에게 물었나요? | 단계, 도구, 사람, 증거원과 전환 지점을 찾는다. |
| Q3 | 첫 문장을 쓰기 전에 가장 먼저 떠올린 장면이나 정보는 무엇이었나요? 그것을 어디에서 확인했나요? | 기록의 최초 입력과 관찰 근거가 기억·사진·메모 중 어디서 오는지 확인한다. |
| Q4 | 그날 가장 오래 걸린 지점에서 무슨 일이 있었나요? 그 부분을 끝내기 위해 실제로 무엇을 했나요? | 가장 큰 비용, 멈칫, 우회로를 최근 행동으로 확인한다. |
| Q5 | 마지막으로 저장하거나 보내기 전에 무엇을 보고 “끝났다”고 판단했나요? 그 전에 실제로 고쳐 쓴 부분은 무엇이었나요? | 완료 기준, 검토 규칙, 최종 행동을 확인한다. |

### 중립 탐침 5개

| # | 질문 | 질문 의도 |
|---|---|---|
| Q6 | 같은 활동을 한 아이들의 기록에서 공통으로 둔 부분과 다르게 쓴 부분을 실제 문장 기준으로 설명해 주세요. | 공통 골격과 아동별 차이를 만드는 실제 규칙을 찾는다. |
| Q7 | 작성 중 아이 행동이 기억나지 않았던 가장 최근 순간에는 어떤 순서로 확인했나요? | 기억 공백을 복원하는 증거원, 확인 순서, 실패 시 행동을 찾는다. 최근 사례가 없으면 없다는 사실을 남긴다. |
| Q8 | 그 기록을 일과 중 끝내지 못했던 가장 최근 날에는 어떤 일이 먼저 있었고, 언제 다시 이어 썼나요? | 시간 제약의 원인과 업무시간 밖으로 넘어가는 경계를 확인한다. |
| Q9 | 한 단계에서 다른 단계로 옮길 때 복사·재입력·사진 찾기처럼 다시 해야 했던 일은 무엇이었나요? | 도구 간 전환과 반복 입력의 비용을 확인한다. |
| Q10 | 그날 계획한 방식대로 되지 않았던 예외나 결국 빼고 보낸 내용이 있었나요? 실제로 어떻게 마무리했나요? | 예외, 제약, 실패 유형과 최종 우회로를 확인한다. |

### 질문자가 피할 표현

- ❌ “자동으로 문장을 써 주면 쓰시겠어요?” → ✅ “지난번에는 첫 문장을 어떻게 쓰기 시작했나요?”
- ❌ “개별화가 제일 힘드시죠?” → ✅ “그날 가장 오래 걸린 지점은 어디였나요?”
- ❌ “결국 사진 정리가 필요하신 거죠?” → ✅ “사진을 본 다음 실제로 무엇을 했나요?”
- ❌ “다음에는 어떻게 하실 것 같아요?” → ✅ “가장 최근에는 어떻게 끝냈나요?”

## 2. 인터뷰 착수 기록

### 로그 1 — 보육교사 A

- **기록 일시**: 2026-09-09 20:54:44
- **Q1. 최근 작성 시점·분량·소요 시간은?**
  - **A.** “13시 / 6명 / 20-30분”이었습니다.
- **Q2. 작성 직전부터 끝까지 어떤 순서로 했나요?**
  - **A.** 어떤 놀이를 했는지와 특이사항을 먼저 떠올렸습니다. 놀이를 자세히 적고, 아이 특성에 맞게 문장을 나눈 뒤 특이사항과 전달사항을 확인했습니다.
- **Q3. 첫 문장 전에 무엇을 먼저 떠올렸나요?**
  - **A.** “어떤 놀이를 했는지, 특이사항”부터 떠올렸습니다.
- **Q4. 가장 오래 걸린 지점은?**
  - **A.** “특이사항 작성”이 가장 오래 걸렸습니다.
- **Q5. 완료 기준과 실제 수정 부분은?**
  - **A.** 놀이가 자세히 묘사됐는지를 봤고, 특이사항 및 전달사항을 다시 고쳤습니다.
- **Q6. 같은 활동을 한 아이들은 어떻게 다르게 썼나요?**
  - **A.** “네 / 특성에 맞게 작성”했습니다.
- **Q7. 기억나지 않았을 때 어떤 순서로 확인했나요?**
  - **A.** “메이트와 이야기”해서 기억을 확인했습니다.
- **Q8. 일과 중 끝내지 못한 가장 최근 원인은?**
  - **A.** “네 / 업무 우선 순위에서 밀림”이 원인이었습니다.
- **Q9. 단계 사이에서 다시 해야 했던 일은?**
  - **A.** 기억이 부족할 때 메이트에게 상황을 다시 물었습니다. 별도의 사진이나 메모 사용은 말하지 않았습니다.
- **Q10. 예외나 빼고 마무리한 내용은?**
  - **A.** 추가 불편 사항에는 별도 내용을 남기지 않았습니다. 특이사항과 전달사항은 빼지 않고 다시 확인하는 쪽으로 마무리했습니다.

### 관찰 1 — 보육교사 G(로그 7)

| 관찰 항목 | 관찰 내용(확인된 행동) | 스펙 후보 |
|---|---|---|
| 단계와 도구 | ① 14시 휴게시간에 5명분 알림장 시작 → ② 가장 활발한 놀이를 떠올리고 당일 사진·메모 확인 → ③ 사진 선택·정리에 약 30분 사용 → ④ 아이별 말과 행동을 넣어 작성 → ⑤ `[관찰 > 배움 읽기 > 놀이 지원 > 지원 계획]` 확인 → ⑥ 일지는 집에서 21시에 시작해 약 30분 작성 | 사진·메모를 아동 및 활동과 연결해 보는 근거 패널. 알림장과 일지의 세션·완료 기준을 구분하는 흐름. 교육과정 항목 점검표. |

|---|---|---|
| 단계와 도구 | ① 놀이 중 다른 아이와 부딪힌 상황을 직접 봄 → ② 아이들과 상황을 이야기함 → ③ 부모의 오해가 없도록 설명 방식 결정 → ④ 알림장 문장 작성 → ⑤ GPT로 문장 전체를 다듬음 → ⑥ 자연스러운 말인지 여러 차례 검토 후 보냄 | 사건의 관찰 사실·당사자 발화·전달사항을 분리해 입력. 원문과 수정문을 나란히 보고 교사가 최종 확정하는 검토 단계. |
| 전환(Handoff) | 직접 본 사실과 아이들과 나눈 이야기를 초안으로 옮긴 뒤, 알림장 화면에서 GPT 화면으로 초안을 복사하고 교정문을 다시 알림장으로 옮겼다. 이 왕복을 2회 반복해 복사·붙여넣기가 총 4회 발생했다. | 각 수정 단계에서 사실이 추가·삭제·변형됐는지 확인 가능한 변경 비교가 필요함. |
| 우회로(Workaround) | 문장을 자연스럽게 만들기 위해 GPT를 사용한 뒤 결과를 여러 차례 다시 검토함. | 문장 교정과 사실 확인을 분리하고, 교정 결과를 자동 확정하지 않음. |
| 멈칫(Hesitation) | “다친 부분에 대해 어떤식으로 설명”할지 정하는 구간에서 18초간 멈췄다. GPT가 다듬은 문장을 초안과 대조하며 3회 다시 읽었고, 이 과정을 포함해 전체 약 10분이 걸렸다. | 민감 사건의 작성·검토 횟수, 초안 대비 최종 수정량을 평가 지표로 측정. |

- **진술과 관찰의 차이**: 이 교사는 일상 활동 알림장을 대부분 작성하지 않았지만, 부상은 별도 기록했다. 따라서 “매일의 반복 기록”만으로 범위를 잡으면 중요한 예외 흐름을 놓친다.

### 관찰 3 — 보육교사 I(로그 9)

- **일시**: 2026-09-15
- **방법**: 기존 작업물 역추적. 오후 2시경 9명분을 약 1시간 작성한 흐름 확인.

| 관찰 항목 | 관찰 내용(확인된 행동) | 스펙 후보 |
|---|---|---|
| 단계와 도구 | ① 오늘 활동 내용 정리 → ② 사진을 하나씩 분류·선택 → ③ 공통 활동 문장 작성·재사용 → ④ 아이별 특별 반응이나 작품 내용을 한 문장 이상 추가 → ⑤ 부모가 하루를 바로 상상할 수 있는지 확인 | 공통 활동을 한 번 작성하고 아동별 관찰 한 문장을 분리해 채우는 구조. 사진을 아동별 관찰과 연결하는 기능. |
| 전환(Handoff) | 9명분을 작성하며 사진 화면과 기록 화면을 9회 오갔다. 첫 기록의 공통문을 나머지 8명에게 복사한 뒤, 각 기록에 아동별 반응이나 작품 내용 한 문장을 추가했다. 기억이 비면 사진으로 돌아간 뒤 아동에게 다시 확인했다. | 공통 내용과 아동별 내용을 명확히 구분하고, 근거 사진에서 해당 아동 기록으로 바로 이동할 수 있어야 함. |
| 우회로(Workaround) | 사진으로 확인하거나 아동에게 직접 물음. 사진으로도 모르고 아동이 하원했으면 행동 내용을 제외함. 행사가 여러 개면 앨범·알림장을 두세 번 작성함. | 근거가 없는 항목은 생성하지 않고 “확인 불가/생략” 상태를 유지. 같은 활동 근거의 중복 입력을 줄이는 구조. |
| 멈칫(Hesitation) | 비슷한 사진 후보를 4회 앞뒤로 넘기며 비교했고, 한 아동의 반응이 분명하지 않아 11초간 멈췄다. 사진을 하나씩 고르고 분류한 뒤 각 아동의 다른 반응을 짧게 쓰는 단계에서 시간이 걸렸다. | 사진 분류 시간, 아동별 문장 작성 시간, 근거 없음으로 생략된 항목 수를 평가 지표로 측정. |

- **진술과 관찰의 차이**: “유아반은 글을 복붙해도 된다”는 진술만 보면 전면 일괄작성처럼 보이지만, 실제 완료 규칙에는 모든 아동의 특별 반응 또는 작품 내용 한 문장이 포함됐다. 공통문 재사용과 개별화는 동시에 일어났다.

## 5. 핵심 Job Story

> **내가 여러 아이의 알림장과 일지를 제한된 시간 안에 작성해야 할 때, 나는 사진·메모·동료·아동 확인으로 관찰 사실을 다시 찾고 공통 활동과 아이별 행동을 구분해 기록하고 싶다. 그래서 부모가 아이의 하루를 구체적으로 이해하고 기록을 퇴근 후로 미루지 않을 수 있도록.** (로그 1, 2, 4, 5, 6, 7, 8, 9, 10)

### 온톨로지 어휘로 되쓰기

핵심 Job Story는 다음 여덟 클래스의 관계만으로 다시 쓸 수 있다.

```text
Teacher --performs--> WritingSession --uses--> EvidenceSource
WritingSession --produces--> ChildcareRecord --about--> Child
ChildcareRecord --includes--> Observation --occurs_during--> Activity
ChildcareRecord --shared_with--> Guardian
```

- `Teacher`가 제한된 시간의 `WritingSession`에서 사진·메모·동료·아동 등의 `EvidenceSource`를 사용한다.
- `WritingSession`은 각 `Child`에 대한 `ChildcareRecord`를 만든다.
- `ChildcareRecord`는 공통 `Activity` 중 확인된 아이별 `Observation`을 포함한다.
- 검토를 마친 `ChildcareRecord`는 `Guardian`과 공유된다.
