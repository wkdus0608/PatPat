# PatPat FE

React Native + Expo 프론트엔드다. 녹음·날짜별 기기 저장과 보관함의 목록·재생·단건 삭제를 포함한다.

## 실행

검증한 환경은 Node.js 24.22.1, pnpm 11.25.0, Expo SDK 58이다. 의존성 버전은 `pnpm-lock.yaml`에 고정된다.

저장소 루트의 터미널에서 실행한다. PowerShell에서는 `.cmd`를 사용하면 실행 정책 오류를 피할 수 있다.

```powershell
cd FE
pnpm.cmd install
pnpm.cmd start --clear
```

Expo SDK 58에 맞는 Expo Go에서 **이번 실행의 QR 코드**를 스캔한다. 기존 화면이 유지되면 Expo Go를 완전히 종료한 뒤 다시 연결한다. `pnpm.cmd web`은 화면 미리보기이며 휴대전화 파일을 읽거나 재생·삭제하지 않는다.

## 구현 범위

- 녹음·관찰일지 작성·보관함의 하단 탭. 관찰일지 작성은 준비 중 화면이다.
- 발표자료 기반 크림색 배경, 갈색 제목, 둥근 카드, 파스텔 강조색.
- 상단 ‘PatPat’ 왼쪽에 사용자가 제공한 [로고](assets/patpat-logo.png) 표시. PNG를 그대로 복사했으며 화면에서 여백이 적게 보이도록 표시 영역만 조정한다.
- 녹음 시작, 경과 시간, 중지 후 저장, 반복 녹음.
- 녹음 화면은 중앙 녹음 카드와 상태·저장 결과 안내로 구성한다. 사용자 요청에 따라 소개 문구·오늘 개수·최근 파일 카드·하단 장식을 제거했다.
- 중복 조작 차단, 녹음 중 탭 이동 제한, 앱 전환·native 중단 감지.
- 파일 저장 실패 시 원본 유지와 저장 재시도. 실패를 정상 저장으로 표시하지 않는다.

화면에는 개수·최근 파일 정보를 전달하지 않으며 앱 진입·재활성화 때 화면 표시용 집계를 조회하지 않는다. 저장·제어 코드의 내부 집계 기능과 기존 자동 검사는 유지한다.

### 보관함

- 종류 선택 → 녹음 파일 / 작성한 관찰일지 → 목록 → 개별 상세.
- 녹음은 날짜·시각 최신순으로 조회하고, 상세에서 재생·일시정지·처음부터 듣기·확인 후 단건 삭제가 가능하다.
- 뒤로가기·탭 이동·앱 전환 시 재생을 정리한다. 삭제 실패는 성공으로 표시하지 않는다.
- 관찰일지는 목록·읽기 전용 상세 표현을 준비했지만 저장·조회 공급원이 없어 실앱은 **연결 준비 중**이다. 실제 저장 기록처럼 예시를 표시하지 않는다.

### 마이크 사용 전제

요청에 따라 권한 요청·거부 안내·설정 이동 기능은 제외했다. 앱은 현재 권한을 읽기만 하며 마이크 권한 요청 함수를 호출하지 않는다. 실제 녹음은 **이미 마이크 사용이 허용된 테스트 기기**가 필요하다.

새로 설치한 앱에서 권한이 없는 경우에는 녹음 시작이 실패한다. Android 개발 기기는 앱 설치 후 다음과 같이 OS 권한을 미리 허용할 수 있다. 이것은 향후 사용자용 권한 흐름을 대신하는 기능이 아니다.

```powershell
adb shell pm grant com.patpat.frontend android.permission.RECORD_AUDIO
```

위 패키지명은 독립 앱 빌드의 `app.json` 값이다. Expo Go는 앱 패키지가 다르므로 이미 허용된 Expo Go 환경을 사용한다. iOS의 최초 설치 권한 흐름과 실제 기기 동작은 아직 검증하지 않았다.

## 파일 저장

녹음 시작 시 기기의 현지 날짜·시각을 정하고, 앱 전용 document 경로 아래에 저장한다. 개발 PC의 FE 폴더나 서버에 음성을 저장하지 않는다.

```text
recordings/
  2026-11-01/
    2026-11-01_09-10.m4a
    2026-11-01_11-30.m4a
  2026-11-02/
    2026-11-02_09-05.m4a
```

- 초·밀리초·별도 ID를 파일명에 넣지 않는다.
- 같은 분에 저장된 파일이 이미 있으면 새 녹음 시작을 차단한다. 파일을 덮어쓰거나 이름 뒤에 임의 번호를 붙이지 않는다. 다음 분에 다시 시작할 수 있다.
- 23:59에 시작해 다음 날 저장한 녹음은 시작한 날 폴더에 둔다.
- AAC/M4A 설정으로 녹음하며, 다른 파일의 확장자만 바꾸지 않는다.
- 임시 파일은 `.pending`으로 구분하고 정상 저장 파일 집계에 포함하지 않는다. 저장에 성공한 뒤 녹음 캐시를 정리한다.
- 녹음 길이는 현재 녹음 세션에서만 유지한다. 별도 DB·식별자·색인 파일은 없다.
- 저장 실패 파일은 앱이 실행 중인 동안 재시도할 수 있다. 강제 종료·운영체제 종료·앱 삭제 후의 복구는 보장하지 않는다.

## 코드 구성

| 위치 | 역할 |
| --- | --- |
| `App.tsx` | 앱 진입과 화면 연결 |
| `assets/patpat-logo.png` | 사용자가 제공한 상단 로고 원본 사본 |
| `src/ui/` | 디자인·화면·탭 |
| `src/library/` | 보관함 화면·내부 이동·재생·안전한 파일 삭제·관찰일지 데이터 연결 경계 |
| `src/recording/useRecording.ts` | Expo 녹음기·앱 생명주기 연결 |
| `src/recording/nativeEngine.ts` | native 녹음 오류·시작·중지 처리 |
| `src/recording/controller.ts` | 중복 조작·중단·저장·재시도 상태 제어 |
| `src/recording/files.ts` | 날짜·파일명 규칙 |
| `src/recording/storage.ts` | 파일 보존과 날짜별 집계 |
| `src/recording/expoFileStore.ts` | 기기 파일 API 연결 |
| `tests/` | 가상 파일·녹음기를 사용하는 자동 검사 |

SQLite·백엔드 API·전사·분류·초안 생성·공유·실명 매핑은 구현하지 않았다. 파일명과 경로는 `observation_id`가 아니다. 원본 음성을 외부 AI로 보내지 않는다.

## 검사

FE 폴더에서:

```powershell
pnpm typecheck
pnpm test
pnpm export
```

`pnpm export`는 Android·iOS·웹의 코드 묶음을 생성한다. APK·IPA 설치 빌드나 실제 마이크 녹음 검증을 의미하지 않는다. 결과와 남은 기기 확인 항목은 [TEST_RESULTS.md](TEST_RESULTS.md)에 기록했다.
