## 자동 검사의 의미

- 빠른 시작·중지 조작이 녹음·파일 저장을 중복 실행하지 않는다.
- 같은 분의 파일명 충돌이 기존 녹음을 덮어쓰지 않는다. 충돌을 녹음 시작 전에 확인한다.
- 가상 녹음 10건의 날짜별 저장과 저장 객체 재생성 후 집계를 확인했다. 실제 녹음 10회 측정 결과는 아니다.
- 복사·최종화 실패 시 원본이 유지되고, 저장 재시도가 파일을 중복 생성하지 않는다.
- 빈 파일·잘못된 형식·임시 파일을 정상 파일로 집계하지 않는다.
- 앱 전환 준비 중의 녹음 시작 취소, 녹음 중단, 종료 실패 후 재시도를 가상 녹음기로 확인했다.
- native 종료 오류 이벤트가 발생하면 불완전 파일을 저장 성공으로 처리하지 않는다. 성공 이벤트가 뒤에 와도 해당 녹음의 오류를 지우지 않는다.
- 자정을 넘긴 녹음의 시작일 유지, 저장 완료 후 목록 읽기 실패와 저장 실패의 구분을 확인했다.

테스트의 파일 내용은 합성 문자열·가상 데이터다. 식별 가능한 음성·실제 아동 이름·실명 매핑은 포함하지 않는다.

## 실제로 확인하지 못한 범위

- Android·iOS 기기에서 마이크 녹음과 M4A 재생.
- 실제 기기에서 10회 반복 녹음, 재실행 후 파일 보존, 저장 공간 부족·전화·화면 잠금·백그라운드 처리.
- native 이벤트의 실제 전달 시점, 제조사별 녹음 중지 동작.
- 모바일 화면의 실제 렌더링, 큰 글자·작은 화면의 가독성과 탭 이동 조작.
- 브라우저 화면 확인은 실행 권한이 거절되어 수행하지 못했다. 코드 묶음 성공을 시각 검증으로 대신하지 않는다.
- 권한 요청·거부 UX, 백엔드 DB·API, 전사·가명 처리·초안 생성·수정·확정·공유는 이번 구현에 포함하지 않았다.

현재 골든 케이스는 관찰 분류·초안 생성 중심이다. 이 FE 검사는 제품 전체 골든 케이스·AC 통과나 문장 생성 의미 검토 결과가 아니다. 기존 판정 데이터와 AC는 변경하지 않았다.

## 기기 확인 체크리스트

마이크 사용이 허용된 Android 테스트 기기에 설치해 확인한다. 시험 신호나 가상 문장의 합성 음성을 사용한다.

- [ ] 녹음 시작·시간·중지·저장이 실제 동작과 일치한다.
- [ ] 날짜 폴더와 `날짜_시-분.m4a` 파일명을 확인하고 파일을 재생할 수 있다.
- [ ] 서로 다른 분에 10회 녹음한 파일이 모두 유지된다.
- [ ] 같은 분에 다시 시작하면 기존 파일을 보존하며 충돌을 알린다.
- [ ] 앱 재실행 뒤 오늘 개수·최근 파일을 확인하고 추가 녹음할 수 있다.
- [ ] 자정 경계와 앱 재활성화 뒤 날짜·개수가 갱신된다.
- [ ] 녹음·저장 중 탭 이동과 연속 조작이 파일을 유실시키지 않는다.
- [ ] 앱 전환·잠금·전화 등 중단 시 결과가 실제 파일과 일치한다.
- [ ] 저장 공간 부족 시 성공으로 표시하지 않고 재시도할 수 있다.
- [ ] 화면·탭·글자 크기를 확인한다.

위 항목은 미실행 체크리스트이며 측정 결과가 아니다.

- [ ] 삭제 취소·확인·실패·재실행 후 반영과 다른 파일 보존을 확인한다.

관찰일지 실제 생성·확정·영속 저장·조회는 미구현이며, 가상 입력 UI 검증을 실제 기록 조회 완료로 보고하지 않는다. 기존 정본·골든 케이스·AC와 테스트 기대값은 변경하지 않았다.

## FE-03 관찰일지 작성 — 2026-11-02

녹음 다중 선택·가져오기, 아동별 초안 편집·근거 확인, 수정 프롬프트·후보 적용/취소, 확정·공유 화면과 연결 경계를 구현했다. 기존 로고·색상·탭을 유지하고 탭 이동 중 편집을 보존한다. 새 의존성·DB·HTTP 요청은 추가하지 않았다.

기본 앱의 생성·수정·확정 저장은 **미연결**이다. 실제 기기 녹음 목록을 선택할 수 있지만 가짜 초안·저장 성공·보관함 행은 만들지 않는다. 모바일 공유 코드는 준비했으며 실제 저장 성공을 확인한 본문이 있어야 사용할 수 있다.

| 실행 | 결과·확인 범위 |
| --- | --- |
| `pnpm.cmd typecheck` | 통과. 화면·제어·검증·테스트 타입 검사 |
| `pnpm.cmd test` | **123/123 통과, skip 없음.** 기존 85개 그대로 유지 + 작성 제어 14개 + 독립 계약·확정/보관함 연결 검사 24개 |
| `node .expo/writing-render-check.cjs` | 정적 화면 마크업 8개 통과. 미연결 버튼·선택 체크·초안·수정 후보·확정·편집 후 공유 차단·저장 중 상태. 아이콘을 대체한 서버 렌더링이며 시각·실제 터치 검증은 아님 |
| `pnpm.cmd export --max-workers 2` | Android·iOS·웹 코드 묶음 생성 성공. 오프라인 실행이며 기기 설치·실제 공유 검증은 아님 |

자동 검사는 가상 파일·가명 아동·가상 관찰과 연결 함수를 사용했다. 선택 파일 소실·읽기 실패·개인정보 확인 실패·중복 조작·늦은 응답·처리 중 이동과 아동별 편집 보존을 확인했다. 다른 아동·선택 밖 근거, 공통 활동만 있는 아동의 개별 초안, 누락·중복·빈 슬롯 응답도 검사한다.

확정 검사는 교사의 공백·줄바꿈을 포함한 본문을 `{edited_text}`로 그대로 전달하고 모델 경로를 다시 호출하지 않는지 확인한다. 저장 실패·확정 중·미적용 수정 후보·본문 추가 수정은 공유를 막는다. 가상 저장소와 기존 보관함 조회 함수를 연결한 검사에서 성공한 확정문만 정확히 조회했다. **실제 DB·영속 저장 검증은 아니다.**

정적 검사에서 RN 웹의 `accessibilityState.checked`만으로는 체크 여부가 전달되지 않아 명시적 `aria-checked`를 추가했다. 아동 선택·근거 펼침·처리 중 상태도 ARIA 속성을 보완했고 동일한 체크 상태 검사로 재확인했다.

## FE-03 단계별 화면 변경 — 2026-11-04

사용자 요청에 따라 한 화면에 나열된 작성 단계를 녹음 선택·초안 확인·직접 수정·AI 수정 요청·완성본 화면으로 나눴다. ‘다음하기’는 생성까지 시작하고, AI 결과는 초안 화면으로 돌아와 검토하며, 두 ‘완료’는 저장 성공 후 완성본으로 이동한다. 화면별 하단 버튼을 스크롤 밖에 배치하고 탭 복귀 시 편집·선택을 유지한다.

추가 검사는 화면별 입력·버튼 분리, 읽기 전용 초안, 직접 편집과 프롬프트 보존, AI 후보 적용/취소, 저장 실패 시 원래 화면 유지, 확정 전 공유 차단을 확인했다. 연속 뒤로가기와 이탈 확인 중 AI 응답 도착이 단계를 건너뛰던 문제를 재현해 수정했다. 목록에서 사라진 선택 파일은 ‘선택 모두 해제’로 교사가 해제할 수 있다.
