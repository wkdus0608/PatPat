# FE-01 녹음 기능 계획

- 상태: 구현 반영. 실행 결과·미검증 범위는 [검증 기록](../TEST_RESULTS.md) 참조
- 기술: React Native + Expo + TypeScript, `expo-audio`, `expo-file-system`
- 정리일: 2026-11-01 — 반복 설명을 통합했으며 기능 범위·저장 규칙은 유지

## 1. 목표와 화면

교사가 하루에 여러 번 녹음하고 각 파일을 기기에 보관한다.

**흐름:** 녹음 시작 → 시간 표시 → ‘중지하고 저장’ → 결과 안내 → 다음 녹음.

- 상단: 제공된 로고·PatPat·현재 날짜
- 본문: 중앙 녹음 카드, 타이머, 시작·중지·재시도 버튼, 상태·저장 결과
- 하단: 녹음·관찰일지 작성·보관함 탭. FE-01에서는 뒤의 두 탭은 준비 중
- 디자인: 크림색 배경 `#FFFDF7`, 갈색 제목 `#49372C`, 둥근 흰 카드와 파스텔 강조
- 녹음 화면에 소개·오늘 개수·최근 파일 카드·하단 장식은 표시하지 않음

## 2. 범위

| 포함 | 후속 작업 |
| --- | --- |
| 화면·탭, 반복 녹음, 날짜별 기기 저장, 실패 재시도 | 보관함 목록·재생·선택·삭제, 관찰일지 작성·수정·확정·공유 |

- 마이크 권한 요청·거부 안내는 제외한다. 실제 녹음은 마이크 사용이 이미 허용된 기기에서 확인한다.
- SQLite·별도 식별자·관리 DB·백엔드 API·전사·AI 호출은 구현하지 않는다.
- 웹은 화면·탭 미리보기이며 녹음 버튼은 비활성화한다.

## 3. 저장 규칙

앱 전용 document 경로 아래에 저장한다. 개발 PC의 FE 폴더에 저장하지 않는다.

```text
recordings/2026-11-01/2026-11-01_09-10.m4a
recordings/2026-11-01/2026-11-01_11-30.m4a
```

- 폴더는 `YYYY-MM-DD`, 파일명은 `YYYY-MM-DD_HH-mm.m4a`. 24시간제 시·분만 사용하며 초·밀리초·ID는 붙이지 않는다.
- 기기 현지 시간의 녹음 시작 시각을 기준으로 한다. 자정을 넘어 저장해도 시작한 날 폴더에 둔다.
- 하루 개수 제한 없이 파일을 추가하고 재실행 후에도 기존 파일을 유지한다. 자동 합치기·덮어쓰기는 하지 않는다.
- 같은 분의 파일이 이미 있으면 새 녹음 시작을 막고 안내한다. 저장 시에도 충돌을 확인한다.
- 실제 AAC/M4A로 녹음한다. 임시 `.pending`·빈 파일은 정상 저장으로 처리하지 않으며, 파일 보관이 끝난 뒤에만 성공을 표시한다.
- 저장 실패 시 원본을 유지하고, 앱 실행 중 재시도가 파일을 중복 생성하지 않게 한다. 성공 후 캐시를 정리하며 캐시 정리 실패를 저장 실패로 바꾸지 않는다.
- 길이는 현재 세션에서만 유지한다. 내부 파일 집계는 유지하되 화면에 전달하거나 별도 DB·색인 파일을 만들지 않는다.
- 파일명·경로는 `observation_id`가 아니며 녹음 날짜를 실제 관찰일로 확정하지 않는다. 파일명에 실명을 넣거나 원음을 외부 AI·Git에 보내지 않는다.

## 4. 상태·실패 처리

| 상황 | 동작 |
| --- | --- |
| 준비·저장·재시도 중 | 중복 조작과 탭 이동 제한. 녹음 중에도 다른 탭으로 숨은 채 이동하지 않음 |
| 시작 실패·빈 파일·인코딩 오류 | 녹음 중·저장 성공으로 표시하지 않고 재녹음 안내 |
| 중지 실패로 마이크가 계속 동작함 | 녹음 상태와 중지 감시를 유지하며 종료 재시도 |
| 공간 부족 등 저장 실패 | 실패 안내·재시도. 기존 정상 파일 보존 |
| 앱 전환·잠금·전화 등 중단 | 종료·저장 시도 후 실제 결과 안내. 강제 종료·앱 삭제 후 복구는 보장하지 않음 |

## 5. 작업·검증

작업 단위는 **기본 화면·탭 → 녹음 조작 → 파일 저장 → 예외 처리·검증**으로 나눈다. 커밋 실행은 별도 요청에 따른다.

| 확인 종류 | 핵심 기준 |
| --- | --- |
| 자동 검사 | 중복 시작·중지·저장 방지, 실패·재시도·파일 보존, 날짜·충돌·정상 파일 집계 |
| 화면 확인 | 로고·탭·상태 안내·작은 화면·큰 글자, 삭제한 개수·최근 파일 영역이 없는지 |
| 실제 기기 | 서로 다른 분에 10회 녹음·재생 가능 여부, 재실행 후 추가 저장, 자정·중단·저장 실패 |

합성 음성·시험 신호만 사용한다. 자동 검사·코드 묶음 생성·시각 확인·기기 녹음을 구분해 기록하고, 실행하지 못한 플랫폼은 미검증으로 남긴다. 기존 테스트·골든 케이스·AC를 완화하지 않으며 FE 검사를 제품 전체 통과로 보고하지 않는다.
