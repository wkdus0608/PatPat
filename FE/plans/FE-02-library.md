# FE-02 계획 — 보관함

- 상태: 검토 중 · 구현 승인 전
- 작성일: 2026-11-01
- 구현 위치: `PatPat/FE`
- 이 문서는 계획이며 구현·테스트 결과가 아니다.

## 1. 목표와 범위

보관함에서 **녹음 파일 / 작성한 관찰일지 선택 → 목록 → 개별 상세**로 이동한다. FE-01의 로고·색상·하단 탭을 유지하며 녹음 화면에 개수·최근 파일 카드를 다시 추가하지 않는다.

| 이번 기능 | 후속 |
| --- | --- |
| 종류 선택·목록·상세·뒤로가기 | 작성에 사용할 녹음의 다중 선택·전달 |
| 실제 기기 녹음 목록·재생·단건 삭제 | 이름 변경·합치기·가져오기·일괄 삭제·복원 |
| 관찰일지 목록·읽기 전용 상세 UI와 미연결 상태 | 관찰일지 작성·수정·재요청·확정·삭제·공유 |
| FE 데이터 공급 경계와 가상 입력 검증 | DB·조회 API·인증·실명 매핑·전사·외부 AI |

현재 실제 데이터는 FE-01이 저장한 기기 녹음이다. 관찰일지 작성·영속 저장·조회는 미구현이며 SPEC에도 목록·최종 본문 조회 계약은 없다. [BE 설계 계획](../../BE/계획/1.%20백엔드%20구조%20설계.md)은 예정 방향으로만 참고하고, 이번 FE에서 DB·저장 형식·새 API를 정의하지 않는다.

## 2. 화면과 이동

- 첫 화면: ‘보관함’ 제목 아래 ‘녹음 파일’·‘작성한 관찰일지’ 카드. 카드 전체를 눌러 이동한다.
- 녹음: 종류 선택 → 날짜별 목록 → 파일 상세·재생.
- 관찰일지: 종류 선택 → 목록 또는 연결 준비 중 → 읽기 전용 상세(데이터 제공 시).
- 뒤로가기: 상세 → 목록 → 종류 선택. Android 뒤로가기도 동일하며 첫 화면에서는 녹음 탭으로 돌아간다.
- 다른 하단 탭에서 재진입하면 종류 선택부터 표시한다. 상세에서 목록 복귀 시 가능한 범위에서 스크롤을 유지한다.
- 하단 탭과 보관함 선택 상태를 유지하고, 화면 제목·뒤로가기·넉넉한 터치 영역으로 위치와 동작을 알린다.
- 기존 녹음 준비·녹음·저장·재시도 중 탭 이동 제한을 유지한다. 녹음과 재생은 동시에 실행하지 않는다.

## 3. 녹음 목록·재생·삭제

### 목록

- 앱 내부 `recordings/YYYY-MM-DD/YYYY-MM-DD_HH-mm.m4a` 규칙과 기존 파일명 검사를 재사용한다.
- 날짜별로 묶어 날짜·시각 모두 최신순으로 표시한다. 추가 날짜 선택 단계 없이 시작 시각·파일명을 누르면 상세를 연다.
- `.pending`·0바이트·잘못된 이름·폴더와 날짜가 다른 파일은 정상 목록에서 제외한다.
- 재진입·앱 재활성화·새로고침 때 실제 파일을 다시 읽고, 다건 목록은 행 재사용이 가능한 목록으로 표시한다.
- 읽는 중·정상 빈 목록·읽기 실패를 구분하고 실패 시 재시도를 제공한다. 빈 목록에는 녹음 탭 이동을 제공한다.
- 파일 날짜는 녹음 시작일이며 실제 관찰일로 해석하지 않는다. 모든 파일을 재생기에 미리 불러오지 않는다.

### 상세·재생

- 파일명·시작 날짜·시각, 재생·일시정지·처음부터, 현재 시간·전체 길이·진행 상태를 표시한다.
- 길이는 선택한 파일을 재생기가 확인한 뒤 표시한다. 확인 전 임의의 길이를 확정하지 않는다.
- 상세 진입만으로 재생하지 않고 한 번에 한 파일만 재생한다. 종료 후 다시 들을 수 있게 하며 다음 파일은 자동 재생하지 않는다.
- 파일 전환·뒤로가기·탭 이동·앱 배경 전환 시 이전 재생기를 중지·정리하고 복귀해도 자동 재생하지 않는다.
- 파일 소실·손상·재생 실패를 안내하고 재시도·목록 갱신을 제공한다. 이전 파일의 늦은 응답이 새 선택을 덮지 않게 한다.
- 탐색 슬라이더·속도 조절·백그라운드 재생은 제외한다.

### 단건 삭제

1. 상세의 ‘녹음 삭제’ → 재생 중이면 일시정지 → 파일명과 복원할 수 없다는 확인 안내.
2. 취소하면 파일·상세를 유지하고 자동 재생하지 않는다.
3. 삭제를 확인하면 재생기를 정리하고 **앱 내부 정상 녹음 파일 하나만** 삭제한다. 임의 경로·폴더는 삭제하지 않는다.
4. 실제 삭제 성공 후 목록에서 제거하고 돌아간다. 마지막 파일이면 빈 목록을 표시한다.
5. 처리 중 중복 삭제를 막고, 실패 시 성공으로 표시하거나 항목을 제거하지 않으며 재시도를 제공한다.

삭제는 기기 원음에만 적용하고 관찰일지·관찰 데이터는 함께 삭제하지 않는다. 근거 스냅샷 영속 보존은 미구현이며, 향후 녹음·관찰·기록 연결 시 BE와 삭제·근거 보존 계약을 맞춘다.

## 4. 관찰일지 표현과 데이터 경계

- 실앱 기본값은 **‘관찰일지 연결 준비 중’**이다. 연결 전 상태를 ‘0건’·조회 오류로 표시하지 않는다.
- 공급원의 정상 빈 결과에만 ‘아직 저장된 관찰일지가 없어요’를 표시한다. 로딩·조회 실패·본문 누락·잘못된 상태는 별도로 안내한다.
- 교사가 확정한 `완료` 기록을 기본 대상으로 한다. `작성중`·`검토중`을 완료로 바꾸지 않으며 임시저장·이어쓰기는 작성 기능에서 다룬다.
- 목록은 제공된 아동·`record_id`를 구분한다. `child_id` 또는 승인된 로컬 표시명, 실제 상태와 관찰일지 구분을 사용한다.
- 제목이 없으면 ‘C01 관찰일지’처럼 제공 정보로 표시한다. 작성일·기간은 제공된 경우만 표시하고 없으면 생략한다.
- 녹음 날짜로 기록 날짜·대상 기간을 추정하거나 새 API 필수값을 추가하지 않는다. 정렬은 조회 계약 확정 전 공급원 순서를 유지한다.
- 상세는 **교사가 확정해 저장한 최종 본문과 줄바꿈을 그대로** 표시한다. 최종 본문이 없으면 불러오기 실패로 안내한다.
- confirm의 `edited_text` 저장 계약만으로 최종 조회 형식을 가정하지 않는다. 초안의 `common_text`·개별 문장을 조합해 확정본으로 표시하지 않는다.
- 항목 구조가 제공되면 있는 항목만 표시한다. 없는 단계·사실·근거 원문을 생성하지 않는다.
- 읽기만으로 상태 변경·확정·외부 AI 호출을 하지 않으며 수정·재요청·확정·공유·삭제 버튼도 추가하지 않는다.
- 가명 코드·가상 입력으로 UI를 검증하되, 실앱에 예시를 실제 저장 기록처럼 노출하지 않는다. 실제 저장·최종 본문 조회 검증은 연동 후 수행한다.

## 5. 작업과 검증

기존 React Native·TypeScript·Expo Audio·FileSystem을 우선 사용하고 보관함 화면·파일 연결·재생 제어·관찰일지 공급 경계를 나눈다. 새 DB·식별자·네비게이션 라이브러리는 추가하지 않는 기본안이다.

커밋 단위: ① 선택·화면 이동 ② 녹음 목록 ③ 상세·재생 ④ 확인 후 단건 삭제 ⑤ 관찰일지 표현·미연결 처리 ⑥ 검증·실행 안내. 사용자가 단계별로 커밋하기 좋게 묶고 커밋 실행은 별도 요청을 따른다.

| 검증 | 확인할 내용 |
| --- | --- |
| 이동·상태 | 종류/목록/상세/뒤로가기, 다른 항목 혼입·늦은 응답 방지, 미연결/빈 목록/실패 구분 |
| 파일·삭제 | 여러 날짜·다건 최신순, 비정상 파일 제외, 재조회·파일 소실, 삭제 취소·중복·실패·성공, 대상 외 파일 보존 |
| 재생 | 단일 재생·연속 조작·일시정지·종료·재시도, 이동/배경 전환 정리, 녹음과 동시 실행 차단 |
| 관찰일지 | 완료 대상·제공 최종 본문 그대로 표시, 본문 누락·데이터 오류, 가상 입력 검증과 실앱 미연결 |
| 회귀 | 기존 FE-01의 31개 자동 검사와 정본 골든 케이스·AC를 완화·삭제·비활성화하지 않음 |

- Android: FE-01 시험 녹음의 실제 목록·재생·삭제, 서로 다른 분·날짜 다건, 재실행 후 파일 보존·삭제 반영, 전화·잠금·앱 전환을 확인한다.
- 화면: 로고·날짜·뒤로가기·긴 파일명·스크롤·작은 화면·큰 글자·탭 가독성을 확인한다. iOS는 기기가 준비되면 별도 검증한다.
- 웹은 이동·상태 미리보기이며 휴대전화 파일 조회·재생·삭제가 연결된 것처럼 표시하지 않는다.
- 자동·타입·코드 묶음·시각·실기기 검증을 구분해 기록한다. 기존 결과·YAML 구문 검사를 FE-02 통과로 재사용하지 않으며 실행하지 못한 항목은 미검증으로 남긴다.

## 6. 완료 수준과 구현 시작

녹음 보관함은 실제 기기 파일 목록·재생·단건 삭제를 목표로 한다. 관찰일지 보관함은 **목록·상세 UI와 미연결/데이터 상태 처리까지**이며 실제 작성·저장·최종 조회 완료로 보고하지 않는다.

기기 원음 외부 전송 금지, 교사 확정 전 완료·발송 금지 등은 [SPEC](../../docs/SPEC.md)과 [작업 규칙](../../AGENTS.md)을 따른다. 파일 경로를 `observation_id`로 쓰지 않으며 테스트에는 가상 데이터·합성 음성만 사용한다.
