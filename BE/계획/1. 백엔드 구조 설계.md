# 쓰담쓰담 백엔드 작업 계획

## 확정한 MVP 결정

- 기술: Python 3.11 이상, FastAPI. 백엔드 코드는 `BE/` 안에 둔다.
- 로그인: 사전에 준비한 테스트 계정만 사용한다. 교사별 소유권은 로그인 정보에서 결정한다.
- 아동: 설정 탭에서 전체 명단을 관리하며, 서버 DB의 실명과 고정 `child_id`로 연결한다. 일지 작성 시 아동을 매번 선택하지 않는다.
- 녹음·AI: 앱이 녹음 파일을 서버에 업로드하고 외부 STT API로 전사한다. MVP에서는 가명 처리를 생략하고, 일지 생성 AI에 전사문과 아동 명단을 전달한다. API 키는 서버에 보관한다.
- 일지: 선택한 녹음만 사용해 명단의 아동별 초안을 만든다. 불명확한 관찰은 임의 배정하지 않고 확인 필요로 남긴다. 교사가 수정·확정한다.
- 공유: 확정된 텍스트를 앱의 복사·OS 공유로 전달한다.
- 저장: SQLite에 명단·메타데이터·텍스트를 저장하고, 원음은 서버의 비공개 파일 영역에 둔다.
- 개인정보·STT 처리 변경은 사용자가 이번 MVP 범위로 직접 결정했다. 이후 기기 내 전사를 도입할 수 있게 STT 연결을 분리한다.
- 사용자가 테스트를 진행하는 것으로 정정했으므로 기능에 필요한 계약·경계·실패 테스트를 추가하고 실행한다.

## BE-00 완료 범위

- FastAPI 앱과 OpenAPI·Swagger 경로를 제공한다.
- `GET /health`는 `{"status":"ok"}`를 반환한다.
- 오류 응답을 `{ "error": { "code", "message", "details" } }` 모양으로 통일한다.
- 공통 작업 상태는 `queued`, `running`, `completed`, `failed`로 둔다.
- 구현되지 않은 `/api/v1/*` 경로는 `501 NOT_IMPLEMENTED`를 돌려준다.
- DB·파일 저장·STT·일지 생성 기능은 아직 연결하지 않는다.
- `/health`, 미구현 응답, 404, OpenAPI 계약 테스트를 실행해 통과했다.

## BE-01 완료 범위

- `POST /api/v1/auth/login`과 `GET /api/v1/auth/me`의 입출력 모델·오류·OpenAPI를 정의했다.
- `AuthService`, `AuthRepository`, 불변 `TeacherContext`와 서비스 주입 지점을 제공한다.
- 인증 정보에서 교사 ID를 결정하고, 다른 교사 자료에는 `404`를 반환하는 공통 소유권 검사를 제공한다. 후속 기능의 저장소 쿼리도 인증된 교사 ID로 제한해야 한다.
- 기본 서비스는 `501 NOT_IMPLEMENTED`를 반환한다. 실제 계정 저장, 비밀번호 해시 검증과 토큰 발급·검증은 별도 구현 범위다.
- 인증 누락·형식 오류는 `401`, 잘못된 로그인 요청은 `422`로 처리한다. 인증 오류의 `WWW-Authenticate` 헤더를 유지한다.
- 상세 계약은 `../docs/AUTH.md`, 원래 스펙의 추가 결정은 `../../docs/SPEC.md` 5-1절에 기록했다.
- 2026-10-29 `BE/`에서 `python -m pytest -q`를 실행해 BE-00 포함 25개 테스트가 통과했다. 정상 인증과 토큰 거부 응답은 테스트 대체 서비스로 검증했으며, 실제 계정·암호·토큰 보안 검증 결과가 아니다.

## BE-02~04 동시 진행 결과 (2026-11-02)

- BE-02: 명단 목록·등록·이름 수정·비활성화, 고정 ID/과거 기록 보존 계약.
- BE-03: multipart 업로드·목록·상세·인증 재생·삭제, 메타데이터/MIME/추가 필드 검증, 비공개 저장소 인터페이스.
- BE-04: 전사 요청·실패 재시도·작업/최신 결과 조회, 상태 정합성·중복 요청·삭제/소유권 경계, 외부 STT 클라이언트와 원자적 예약 저장소 인터페이스.
- `docs/SPEC.md` 5-2절과 기능별 문서에 새 API 필드의 설계 이유와 처리 계약을 기록했다. 기존 생성 골든 케이스의 판정 조건은 바꾸지 않았다.
- 작업 중 원래 체크아웃이 main으로 전환되어 원래 작업을 보호하고자 별도 `PatPat-BE` worktree와 `codex/backend-be02-be04` 브랜치로 이동했다. 원래 main의 이번 작업 변경은 이동했다.
- `BE/`에서 `python -m pytest -q`: 기존 BE-00/01 포함 100개 통과. 정상/실패 처리는 대체 서비스로 확인했으며 실제 DB·파일 저장/삭제·외부 STT 호출과 품질은 미검증이다.
