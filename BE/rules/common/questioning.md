# 역질문 정책

> 교사가 입력한 모든 블록을 한 번에 읽고, 애매하거나 확인이 필요한 부분에만 묻는다.

## 원칙

1. 질문은 학급 전체에 대해 한 번만 한다. 아이마다 묻지 않는다.
2. 질문이 없어도 된다. 모호한 곳이 없으면 0개로 끝낸다.
3. 학급 전체 합쳐 최대 10개이고, 보통 0~3개다. 직접 쓰는 것보다 빨라야 한다.
4. 사실이 틀릴 수 있거나, 입력된 활동을 관찰영역과 연결할 구체적인 행동·말·반응이 빠졌을 때 묻는다. 말투, 문장 길이, 표현 취향은 묻지 않는다.
5. 상한을 넘는 모호함은 묻지 않는다. 입력에 있는 사실만으로 보수적으로 쓰고 "확인 필요"로 표시한다.
6. 교사가 건너뛴 질문은 추측하지 않는다. 입력에 있는 사실만 쓴다.

## 묻지 않는 것

- 관찰영역: 블록 옆 영역 칩으로 받는다.
- 장소와 시간: 블록 옆 선택 칩으로 받는다.
- 아이마다 반복되는 질문("오늘 무엇을 했나요?"). 개별 내용이 없는 아이는 질문 대신 "확인 필요"로 표시한다.
- 놀이의 계기. 입력에 없으면 계기를 지어내지 않고 쓰지 않는다.
- 결석한 아이.

## 묻는 경우 (우선순위 순)

1. 사건사고로 보일 때: "사건사고 같아요. 보호자 안내용으로 부드럽게 쓸까요?" 부드럽게 쓰기로 하면, 부상 부위와 정도, 조치처럼 입력에 빠진 핵심 사실만 더 묻는다.
2. 아이 간 불일치나 연결 불명확: 두 블록이 같은 일을 다르게 적었거나, 같은 일인지 알 수 없을 때.
3. 대상 불명: 명단에 없는 이름, "걔"나 "친구"처럼 누구인지 특정할 수 없는 표현, 동명이인.
4. 핵심 관찰 누락: 활동명이나 참여 여부만 적힌 경우(예: “흔들 놀이기구에 탔어요”)에는 기록에 가장 도움이 되는 실제 장면 하나를 묻는다. “다온이가 흔들 놀이기구를 타는 동안 어떤 움직임이나 반응을 보였나요?”처럼 자유 답변으로 묻고, 보지 않은 동작을 질문에 전제하지 않는다. 짧아도 행동이 구체적이거나 다른 블록에 근거가 있으면 같은 내용을 다시 묻지 않는다.
5. 의미가 갈리는 모호함: 도움을 받았는지 혼자 했는지처럼 문장의 의미가 달라지는 경우만.

## 질문 형식

- 한 질문은 한 문장이다. 아이 이름을 넣어 구체적으로 묻는다.
- 확인할 장면을 자유 답변으로 묻는 핵심 사실 질문은 선택지 없이 직접 입력과 건너뛰기를 준다. 다른 질문은 선택지 2~4개를 함께 준다.
- 질문은 한 화면에 모아서 보여 준다.
- 질문마다 종류(사건사고, 불일치, 대상 불명, 모호함)와 관련된 아이를 함께 적는다.
- 이유는 필요할 때만 한 줄로 덧붙인다.

## 질문 예시

| 종류 | 질문 | 선택지 |
|---|---|---|
| 사건사고 | 이든·서윤 이야기는 사건사고로 보여요. 보호자 안내용으로 부드럽게 쓸까요? | 부드럽게 / 그대로 |
| 불일치 | 서윤이가 넘어진 건 이든이가 민 일과 같은 상황인가요? | 같은 상황 / 따로 |
| 핵심 사실 | 서윤이 무릎은 어떻게 했나요? | 닦고 확인 / 연고 / 그대로 둠 / 직접 입력 |
| 대상 불명 | "하준"은 명단에 없어요. 누구를 말씀하신 걸까요? | 명단의 아이들 / 직접 입력 |
